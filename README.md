## ✦ About

**NosiWeb** is an independent web project focused on building clean, fast and accessible websites without unnecessary complexity.

The project combines **frontend development, hosting, maintenance and digital services** into a simple experience designed especially for small businesses and individuals.

> **Built small. Designed carefully. Made to be useful.**

NosiWeb is also a practical **student-built project**, created to develop real-world engineering, design and product-building experience.

## 🧱 Architecture

NosiWeb intentionally uses a lightweight architecture.

```text
                    ┌─────────────────────┐
                    │      Visitor        │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │     nosiweb.net     │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │    GitHub Pages     │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │     index.html      │
                    │                     │
                    │  HTML + CSS + JS    │
                    └─────────────────────┘
```

No unnecessary backend or framework is required for the current landing page.

## ⚡ Performance Philosophy

NosiWeb follows a simple principle:

> **Don't add technology just because you can.**

For a static business website, a lightweight stack can often provide everything required.

That means:

- Minimal dependencies
- No unnecessary frameworks
- Simple deployment
- Easy maintenance
- Fast loading
- Straightforward development

## 🚀 Getting Started

### Clone

```bash
git clone https://github.com/nosiweb/home.git
```

### Enter the project

```bash
cd home
```

### Run

Open `index.html` directly in your browser, or use any local development server.

For example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
